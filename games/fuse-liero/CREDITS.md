# Credits and provenance

Fuse Liero is an original TypeScript adaptation of the real-time worm-combat idea, inspired by Liero (Joosa Riekkinen), Liero Xtreme (Jason Boettcher), and the OpenLieroX contributors.

References inspected: [OpenLieroX downloads](https://openlierox.net/downloads/), [web demo](https://openlierox.net/web-demo/), and [source repository](https://github.com/openlierox/openlierox). The native project includes LGPL code and other individually licensed components; none of its source code, maps, skins, sounds or bundled assets are distributed here. This version does not claim OpenLieroX network or mod compatibility.

The neon cave renderer and desktop worm icon are original code-drawn Fuse artwork. Shared menus, networking and typography use the existing repository dependencies and their licenses.
